# 论文与核心模块重组验收

日期：2026-10-13。

## 实现范围

- `papers.yaml` 将既有 10 个模块组织为 9 篇论文，保留模块编号、目录及旧 CLI 别名。
- 首页以论文为入口；论文详情展示贡献、精选范围、模块进度和必做/已提供函数。
- PPO、DPO、DDPM、DDIM、Flow Matching 等 starter 提供辅助代码，必做函数置于文件顶部；双语题面与契约同步。
- DDPM 的两个模块共用论文入口；Progressive Distillation 明确只覆盖选定的参数化技术。
- 同源社区模块按 arXiv 或 URL 合并；未列入精选列表的新增模块作为可选拓展。
- 保存已通过报告，后续失败或重置最近报告不会抹掉通过状态；兼容原浏览器存储格式。

## 验证结果

- 判题框架及工作流：`python -m pytest tests -q`，55 项通过。
- 全模块质量门：`paperleet ci`，3 轮、1470 个用例、45/45 个错误变体被检测到，86.91 秒。
- 仅使用 starter 和必做函数参考实现拼接：RL 46 项、diffusion 42 项测试全部通过。辅助函数保留 starter 原实现，覆盖真实 T3 训练和采样。
- 前端：`npm --prefix web run check`、`npm --prefix web run build` 通过；检查包含已通过状态持久化、旧记录迁移和可选模块不影响论文完成度。
- 浏览器：检查论文首页、DDPM 两模块详情、中英文切换、模块编辑器辅助代码、论文内前后导航与返回论文入口。

本次调整现有题库结构和练习范围。Submit Paper 仍每次生成一个候选模块，人工审核与隔离执行流程保留；多模块方案生成及个人主页不属于本次实现。
