# Reference notes

The first arXiv version is titled *Object-Level Latent Interventions*; the current version uses *Object-Level Latent Masking*. The package follows [arXiv 2602.11389v2](https://arxiv.org/html/2602.11389v2) and the official [input construction](https://github.com/galilai-group/cjepa/blob/412337d0210bf98cee2ca90c3586ab2ea7ca519e/src/cjepa_predictor.py). Its `prepare_input` starts from mask-token + time + projected-anchor queries, then restores the first frame and unmasked history. The projection's shared bias can be absorbed into the shared mask token used in this interface.

The official [CLEVRER slot-training loss](https://github.com/galilai-group/cjepa/blob/412337d0210bf98cee2ca90c3586ab2ea7ca519e/src/train/train_causalwm_from_clevrer_slot.py) sums separately normalized selected-history and future MSE terms against detached targets. That loop includes time zero for selected slots; this exercise follows the paper's Eq. (5) masked-token indicator and excludes the visible anchor. This difference is explicit in the contract. A single global masked-token average would reweight these terms according to their token counts; tests deliberately use unequal counts. An empty history selection must produce zero instead of NaN.

The anchor preserves object identity without object-index positional embeddings. Jointly permuting slots and mask selections should permute the constructed input identically. Changing a selected object's later historical state should leave the input unchanged, while changing its anchor may change its queries. The scalar matrix-projection oracle tests the direction of the supplied weight matrix.

Masking changes what the predictor observes. It does not physically intervene on the system or prove causal identifiability. The small experiment intentionally uses known coupled trajectories to expose missing-context behavior without claiming the paper's vision or causal-reasoning results. Mutants hide the anchor, leak masked history, train frozen targets or supervise visible history.
