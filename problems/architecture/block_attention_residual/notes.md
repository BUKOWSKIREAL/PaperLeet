# 参考解要点

第 0 维是深度。每个 token 独立选择 embedding、已完成块、当前 partial block。沿时间 softmax 会让不同 token 竞争，改变算子含义。

RMSNorm 有可学习乘法权重，不减均值。分母是特征平方均值加 eps 后开方。只归一化 key；若把归一化后的 key 当 value 聚合，会丢掉原值幅度。

query 全零时应得到来源的算术平均；只有一个来源时必须原样返回；重排来源只改变权重顺序，不改变输出。这些性质可以独立于参考解验证实现。

块边界处不存在 partial source 时必须省略；显式零来源仍参与归一化。调用者已算好各块的输出和，本题不推断每块有多少子层。

教学实验对三个手工向量扫描固定 query。图中误差来自提交代码的实际输出，不表示训练损失，也不用于复现 K3 的规模增益。
