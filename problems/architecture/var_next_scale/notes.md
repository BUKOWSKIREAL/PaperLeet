# 参考说明

累计特征始终保留在**最大分辨率**。加入一个放大后的残差图，将累计和 area 下采样到下一尺度，再保存该输入块。只保留最新残差会丢失粗尺度上下文；加入下一尺度目标 token 会泄漏答案。

尺度因果 mask 包含整个对角块，而不是块内的下三角。对角块大小为 `n_k² × n_k²`，尺度边长不等于 token 数。本题约定 `True = 可见`，所以 `masked_fill(..., -inf)` 应使用它的取反。

测试通过独立的标量查表与通道求和 oracle、精确可见性矩阵、目标扰动及分样本对照验证。T3 将你实现的两个函数与实际 softmax attention 组合，目标变化只能影响更细尺度输出。

本题范围是冻结 tokenizer 的输入构造，使用共享欧氏码本和给定通道投影。原论文中的已学习空间投影、图像编码器/解码器和 Transformer 训练没有在小实验中复现。
