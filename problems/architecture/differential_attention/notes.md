# 参考解说明

先减 logits 再做一次 softmax，不等于两张归一化注意力图相减。缩放使用拆分后每条 Q/K 分支的宽度，不能用翻倍的 V 宽度。两条分支遵守相同的因果依赖。

概率行为 `p`、上游梯度为 `u` 时，softmax 的 VJP 是 `p * (u - sum(p*u))`。测试通过标量循环计算概率，再显式应用解析导数。第二分支的 VJP 乘 `−lambda`；lambda 自身接收 `−sum(A2 * dL/dA)`。

共同偏移实验来自行和恒等式。每张注意力图都把常量 value 偏移 `c` 映射为 `c`，因此差分图映射为 `(1−lambda)c`。这个结论针对本题的逐头归一化之前；完整模型另外包含逐头归一化与输出投影。
