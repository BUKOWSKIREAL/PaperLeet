# 参考说明

归约特征维时保留维度，让均值和方差能够广播回每个特征。先中心化，再计算总体方差；默认的样本方差修正不适用于这里，且在单特征输入时没有定义。

仿射缩放和偏移在归一化之后应用。epsilon 加到方差上，而不是标准差上。方差很小时，这个位置会显著影响数值与梯度。

`post_norm_residual` 复用 `layer_norm(x + sublayer_output, ...)`。先归一化 `x` 再求和是不同的计算。本题关闭 dropout；原始 Transformer 中 dropout 位于子层输出之后、残差相加之前。本题不实现现代 pre-LN 或 RMSNorm 变体。

Toy 为每个 token 设置不同偏移与尺度，以标量计算作为独立对照，展示逐 token 统计量不受其他 token 影响。它不用于证明训练稳定性，也不声称复现论文基准实验。
