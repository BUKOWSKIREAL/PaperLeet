# 参考解要点

状态为 `[B,H,K,V]`，逐通道遗忘乘在 key 行上，不是 value 列上。预测值必须由遗忘后的状态计算，输出则读取本 token 写入之后的状态；顺序不能交换。

对单位长度的重复 key，beta=1 会替换旧预测而非重复累加。beta=0 仍然需要遗忘。alpha 的不同 key 通道独立，不能退化成每个头共享一个门。

K3 的 `exp(A)` 乘在 sigmoid 内部的 logit 上，再用固定负下界乘 sigmoid 的结果。浮点饱和可能产生端点，所以数值测试使用含端点的界限；不能因为单步有界就声称任意长度连乘不会下溢。

避免原地改动状态，让梯度继续传回前一段传入的 initial_state。两段输出拼接应等于一次完整 scan。本题不隐式缩放 q。
