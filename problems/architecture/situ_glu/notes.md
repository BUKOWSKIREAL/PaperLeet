# 参考实现说明

先实现可复用的 `softcap`，再把门控的 softcap、原始 gate 的 sigmoid 与 up 的 softcap 相乘。两条分支的 cap 不同，不能交换或复用一个值。

梯度测试独立使用解析导数。例如 `softcap` 的导数为 `1 - tanh(x / beta)^2`，在有限精度未饱和的情况下，超过 `beta` 仍然可导且通常不为零。测试不要求极端输入在浮点饱和后仍保留非零梯度。

Figure 4 采用 `gate = up = x` 方便观察；实际函数测试同时包含符号相反、大小不同的分支，避免错误实现只在这条对角线上看似正确。图表横轴、采样密度与来源说明可直接核对。

上界检查限制的是激活输出，未覆盖 FFN 后续的输出投影。测试通过不代表已经复现报告中完整模型的稳定性结果。
