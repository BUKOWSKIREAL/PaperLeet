# 参考说明

合并后的投影矩阵按连续列存放不同头的特征。设头宽度为 `d`，第 `i` 个头使用 `w[:, i*d:(i+1)*d]`。独立 oracle 会逐头构造投影，避免与参考实现采用相同的整体 reshape 路径。

Cross-attention 的 query 长度取自 `query`，key 长度取自 `key`。注意力概率沿 key 轴归一化，缩放因子则来自单个头的宽度。提供的注意力内核已经处理这些约定。

注意力输出 `[B,H,Q,d]` 先换成 `[B,Q,H,d]`，才能压平为 `[B,Q,D]`。对 transpose 后的非连续张量，reshape 比 view 更适合。最终的 `@ w_o` 会混合各头输出，仅拼接还没有完成算子。

原论文公式没有投影 bias，本题沿用这一点，并省略 dropout 保证可重复性。四个投影矩阵与 q/k/v 都应保留梯度。全屏蔽行的零输出是对论文公式的工程补充。

Toy 中各头的偏好可用与 `[exp(5/sqrt(2)),1,1]` 及其排列成比例的 softmax 概率精确计算。它展示不同的特征子空间，不涉及训练得到的分工，也不复现原论文翻译实验。
