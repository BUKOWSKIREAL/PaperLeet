# 参考解说明

利用 `(e*r).sum(-1)` 与 `(e*u).sum(-1)` 两个内积施加旋转。只对最终输出 detach 会切断需要的编码器梯度；完全不 detach 则会对随输入变化的变换本身求导，偏离预期替代梯度。

二维 oracle 通过 `atan2(q_y,q_x)-atan2(e_y,e_x)` 得到角度，独立构造正弦/余弦矩阵，不复用参考解的 Householder 公式。高维测试另外验证正交补、模长缩放和相对于锚向量的夹角。

Toy 二次函数的上游梯度为 `2q`。传回 `e` 的梯度沿径向，模长为 `2||q||²/||e||`，一般**不等于**未量化梯度 `2e`。STE 则在同一码本区域处处返回 `2q`。二者是不同的梯度估计选择，不能把它们说成最近邻量化的真实导数。

本题明确排除奇异输入，不在没有唯一旋转的地方规定虚构的唯一答案。选中的码本向量不接收这条重建梯度；完整模型可通过另一个目标或 EMA 更新码本。
