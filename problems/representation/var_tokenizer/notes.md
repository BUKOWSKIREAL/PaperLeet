# 参考说明

残差始终保留原始潜特征分辨率。只在选择当前尺度索引时缩小残差；选出的码必须放大回最大分辨率后再相减。共享码本不代表所有尺度都量化同一张特征图。

参考实现用广播计算平方距离，也可用范数与内积等价计算，但并列最小值必须选择最小索引。通道投影发生在选码之后，其影响必须同时计入下一步残差和累计重建。

测试包含可手算的两尺度案例、非均匀尺度与非恒等通道矩阵的标量最近邻 oracle、独立构造的解码期望、冻结输出语义和样本独立性。对于稠密标量码本和恒等的最后投影，只要残差在码本范围内，最终误差不超过半个量化间距。

toy 中固定码本能改善所选潜特征；误差逐尺度单调下降不是任意已学习投影残差量化的一般不变量。可训练 VQ-VAE 的 autograd 属于另一个实现范围，本题只实现确定性的冻结 token 生成。
