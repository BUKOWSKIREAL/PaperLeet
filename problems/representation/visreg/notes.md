# 参考讲解

Algorithm 1 明确了三个约定：`std(unbiased=False)`、尺度偏差取**平方**、特征和投影结果使用 mean 归约。照搬 VICReg 的方差 hinge 或协方差惩罚会改变本题目标。高斯分位点不包含 0 和 1，避免逆 CDF 出现无穷值。

shape 的前向分母来自数据，反向时却把它视为常数。因此，有限差分梯度检查应在基准点固定分母；每次扰动后重新计算标准差，得到的是另一个函数的导数。方向是给定常量，按列归一化使正的长度缩放不影响结果。排序消除的是样本顺序，沿特征维排序会破坏一维分布比较。

一致性目标中令 `r_v=z_v-g`。所有视图接收直接残差梯度，全局视图还接收均值分支的贡献 `-2 sum_v(r_v)/(G*V*N*D)`。把全局均值 detach 不会改变损失数值，却会改变梯度。

论文公式 (2) 包含 epsilon，展示的 Algorithm 1 没有写出它。本题明确采用公式 (2) 的分母和 Algorithm 1 的 mean 归约。不要求重复投影值的排序有唯一梯度，也不把完全坍缩时某一条优化轨迹作为算法结论。
