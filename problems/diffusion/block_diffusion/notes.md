# 参考解说明

根据局部块编号生成三个小掩码，按噪声/干净的顺序拼成四个象限。块内不能套 token 级因果三角：噪声与干净表征都需要双向访问自己所在的块。

标量 oracle 按块创建可见 key 列表，在各自局部上下文中计算注意力，不调用参考掩码。梯度测试显式推导噪声 query 2 的 softmax VJP，验证每个禁止 key/value 的导数为零。Toy 的影响矩阵通过逐一扰动 value、重跑提交实现测得，不是从元数据直接展示。

块大小为 1 时，这个训练掩码仍有两条流：每个噪声位置读取自己和更早的干净 token，并不是拼接序列上的普通因果掩码。全序列只有一个块时，两条流相互隔离，内部各自双向可见。

验证注意力依赖并不等于验证离散扩散概率或原文的似然下界；它们应作为其他独立模块。
