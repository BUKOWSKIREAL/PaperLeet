# 参考实现说明

令 `d=current-old`、`e=old-target`，逐样本目标展开为 `||e||^2 + beta^2||d||^2 + 2*beta*(2*r-1)<e,d>`。batch 平均前，当前策略梯度为 `2*beta*(beta*d+(2*r-1)*e)`。测试用这个独立展开验证梯度与最优点。

奖励为二分之一时交叉项消失，优化把当前策略拉回旧策略。奖励为零时，拟合负分支会让当前策略相对旧策略朝远离目标的方向移动。丢弃负样本或直接使用带符号 MSE 都会破坏该行为。

论文公式使用特征求和的欧氏范数。生产训练可能将特征归一化和时间权重并入优化约定；harness 明确固定归约方式。本题只实现基本式 (5)，不隐含加入自适应权重、EMA 调度或奖励归一化。

原论文允许任意黑盒采样器收集干净数据。toy 改为给定固定 minibatch，并独立优化每个 velocity 输出，所测最优点展示局部目标，不代表有限容量 denoiser 或整体奖励一定改善。时间方向采用论文 rectified-flow 的数据到噪声约定，由零走向一。

旧 rollout 策略、干净目标和奖励概率都是固定上下文。测试故意为这些输入开启 `requires_grad`，检查意外梯度泄漏。四个 mutation 分别覆盖 beta 倒数、负分支符号、丢弃负样本、训练旧策略。
