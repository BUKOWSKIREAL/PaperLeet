# 题解

Eq. (33) 中，样本只有是所在子集唯一最大值时才有贡献。其排序位置为 i，次大值位置为 j<i，其余 k-2 项有 `C(j,k-2)` 种选法。加权求和即得到前缀公式。对系数和“系数×奖励”分别求累计和，排序后即可算出全部权重。并列项差值为零，恢复原序后结果与并列排序顺序无关。

k=1 使用明确约定的零 baseline，恢复 reward/N 的 REINFORCE；k=N 只保留最大与次大奖励之差，并列最大则全零。k>=2 时统一平移奖励不改变权重。不能直接对变换后的系数做 leave-one-out 均值，因为每个系数已依赖整组样本。

权重已含 `1/C(N,k)`，与 log probability 相乘后沿样本求和，仅对独立组平均。score-function 梯度需要 detach 奖励及采样动作，不能混入 pathwise 梯度。

## 源版本和 toy

题目归于 NeurIPS 2025，固定[修订 v5 Eq. (33)](https://arxiv.org/html/2505.15201v5)，直接从子集定义推导，避开旧版本曾修正的递推式。前缀实现独立编写，并非复制附录代码。Eq. (33) 的空集最大值需要约定，因此显式规定 k=1 零 baseline。不实现 PPO clipping 或完整 LLM 训练器。

Gaussian toy 保留论文标准差和奖励区间，用固定网格展示目标及梯度，不声称训练收敛或模型指标复现。小组 oracle 枚举所有子集；二值策略枚举所有采样批次，将期望梯度与 `k*(1-p)^(k-1)` 比较。四个 mutant 覆盖均值代替最大值目标、未变换奖励、未恢复样本顺序、重复归一化。
