# 题解

[SDPO v2](https://arxiv.org/html/2601.20802v2) Table 2 明确：原尝试成功时，用自身回答作为正确解；否则有同题成功解就优先使用，只有没有成功解时才读环境反馈。先建立“同题且成功”矩阵、选首个候选，再把成功行覆盖为自身索引。多个 peer 取最小索引仅为本题确定性约定，论文未规定该 tie-break。

因此，成功解索引允许等于自身。索引 -1 只表示没有成功解，不代表一定无监督：丰富环境反馈仍可能可用。测试同时提供成功解与丰富反馈，检查真实优先级。

教师 logits detach；反馈可用性同时限制分子和分母。本题计算已给学生前缀上的全词表逐 token reverse KL，按可用 token 平均；下一题实现 Appendix A.3 的压缩。toy 用 categorical 查询教师替代语言模型 reprompting，保留反馈路由，但不复现论文完整训练或基准结果。
