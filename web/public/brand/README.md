# LeetPaper brand assets

The folded paper represents research. Its three connected nodes represent a computational graph, with a mint center node marking the core mechanism of a paper. The mark uses the same geometry as `web/src/Brand.tsx`.

| Asset | Canvas | Use |
| --- | --- | --- |
| `leetpaper-logo-light.svg` | 320 × 80 | Full wordmark on light backgrounds; transparent |
| `leetpaper-logo-dark.svg` | 320 × 80 | Full wordmark on dark backgrounds; transparent |
| `leetpaper-mark.svg` | 96 × 96 | Standalone mark on a rounded indigo square |
| `../favicon.svg` | 48 × 48 | Browser icon, matching the standalone mark |
| `leetpaper-brand-preview.svg` | 1200 × 640 | Light and dark logo sheet with 96, 32, and 16 px icon previews |

| Color | Light theme | Dark theme |
| --- | --- | --- |
| Indigo | `#5158d6` | `#959bff` |
| Mint core | `#078a76` | `#57ddbf` |
| Wordmark ink | `#262626` | `#efeff1` |

The standalone mark and favicon use the same `#5158d6` background, white linework, and `#57ddbf` core in both themes. SVG assets contain native paths and shapes with no external references or runtime fonts. Wordmark glyphs are outlined from Arial Bold; the website header uses its system font stack.
